# ADR 010: Opt-in adaptive review with independent authorization provenance

Status: accepted

Sentinel uses a Luna trajectory classifier and a separate blocking reviewer rather than paying for exact-action review on every tool call. A recent low score can release a different action within a maximum two-call lag; this is deliberately adaptive review, not a per-action safety proof or OS sandbox. Lag zero requires blocking review. New sessions default off, and only an idle interactive parent can enable the guard after reviewing its effective settings and standing preferences.

Pi's persisted user role is not evidence of human origin: it also contains expanded skills/templates, while extension custom messages can become user-role model input. Sentinel therefore records original interactive/RPC inputs before expansion and separates them from execution evidence. Questionnaire authority includes displayed choices or custom human text, never hidden option values or assistant-authored IDs. Global user instructions and explicitly trusted project context are distinguished from untrusted repository steering; context files cannot manufacture direct user approval. These provenance records survive compaction independently of summaries.

Enabled mode persists the fingerprint of the confirmed effective configuration/preferences. Resume, extension reload, and tree navigation must verify it; old enabled entries without an anchor require confirmation. Silently rereading current files would let an agent-authored policy become authority. Incomplete evidence cannot seed reusable low scores and skips the otherwise wasted classifier request. Large original-user histories deliberately keep blocking review rather than silently dropping earlier restrictions.

Bundled delegation uses a typed optional bridge to inject Sentinel last and pass a private live root-authorization snapshot. The task brief cannot widen root authority, and an already-guarded child stays guarded after its parent turns auto off. Arbitrary trusted extension code, user shell commands, and independently launched processes remain outside this boundary. Normal shutdown removes snapshots; abrupt process death can leave private temporary files. See the [feature documentation](../../extensions/sentinel/README.md) for budgets, maintenance, and recovery behavior.
